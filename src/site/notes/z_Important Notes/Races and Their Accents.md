There are so many races, and the DM can only think so much on the fly. So below is a nifty guide to what the DM is more likely than not gonna make a race sound like. Of course, outliers exist; not every ginger is Irish and not every Caucasian is Scandinavian.


| Race                | Accent                   |
| ------------------- | ------------------------ |
| Human               | Estuary British          |
| Elf                 | Irish                    |
| Drow                | Scottish                 |
| Dwarf               | Scandinavian             |
| Halfling            | American                 |
| Gnome               | German                   |
| Deep Gnome          | (Overexaggerated) German |
| Goliath/Firbolg     | Northern English         |
| Goblin              | cOcKnEY                  |
| Orc                 | Cockney                  |
| Tiefling            | New Jersey/New York      |
| Aasimar             | Trans-Atlantic           |
| Githyanki           | Russian                  |
| Harengon            | Crocodile Hunter         |
| Bugbear             | Torbek                   |
| All Fae             | Mayfair/Shakespearean    |
| Genasi              | Italian                  |
| Tabaxi              | Khajiit                  |
| Aarokocra           | Gilbert Gottfried        |
| Autognome/Warforged | Shounen Anime Boy        |
| All Greek Myths     | Greek (duh)              |
| Tortle              | Southern American        |
| Lizardfolk          | Castilian w/ fake lisp   |
